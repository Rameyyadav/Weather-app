# 🌤️ Weather App

A simple React-based weather application that fetches real-time weather data using the **OpenWeather API**.  
Users can search for any city and view temperature, humidity, wind speed, and weather conditions with dynamic icons.

---

## 🚀 Features
- **Real-time weather data** powered by OpenWeather API  
- **Search functionality** to look up any city  
- **Dynamic weather icons** (clear, cloudy, rain, snow, drizzle)  
- **Responsive UI** styled with CSS  

---

## 🛠️ Tech Stack
- **React** (Hooks, useState, useEffect, useRef)  
- **CSS** for styling  
- **OpenWeather API** for weather data  
- **JavaScript (ES6+)**
